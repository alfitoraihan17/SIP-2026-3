# WebGIS PTN Surabaya
Peta interaktif sebaran Perguruan Tinggi Negeri (PTN) di Surabaya, dibuat untuk praktikum mata
kuliah Sistem Informasi Perencanaan (SIP) 2026.
## Lihat Peta
[Buka WebGIS](https://alfitoraihan17.github.io/SIP-2026-3)
## Isi Peta
- Lokasi kampus PTN di Surabaya (ITS, UNAIR, UIN, UNESA, dan lainnya)
- Foto setiap kampus
- Analisis aksesibilitas kampus
